# Digitales Bewerbungs-Portfolio – Jens Overkämping

Willkommen in meinem GitHub-Repository! 

Dieses Projekt dient als digitales Dashboard und Dokumenten-Zentrum für meine Bewerbung im IT-Bereich. Im Rahmen meiner beruflichen Orientierung an der BBS Westmünsterland (Borken) vertiefe ich hier mein praktisches Wissen.

#🛠️ Enthaltene Praxis-Projekte & Ausarbeitungen:
* **Math Drop Ultimate**: Ein interaktives JavaScript-Rechenspiel mit Combo-System.
* **IP-Klassen Analyzer**: Ein Tool zur schnellen Validierung und Analyse von IPv4-Adressen im Selbststudium.
* **Port- & Protokoll-Trainer**: Ein JavaScript-Quiz zum spielerischen Festigen wichtiger Netzwerk-Ports (SSH, RDP, DHCP etc.).
* **Protokoll-Labor**: Fachliche Dokumentation zu DHCP, DNS (A/AAAA/CNAME-Records) und NAT.

*Hinweis: Alle Web-Projekte und Dokumente sind direkt über das Dashboard erreichbar.*
